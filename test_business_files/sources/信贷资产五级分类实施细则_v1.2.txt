# 信贷资产五级分类实施细则

## 文件编号：XDJC-2025-012
## 版本：1.2
## 生效日期：2026-02-10

---

## 第一章 总则

**第一条** 为规范本行信贷资产风险分类管理，真实、全面、动态地反映信贷资产质量，根据《中华人民共和国商业银行法》、《贷款风险分类指引》（银监发〔2023〕1号）等法律法规，制定本细则。

**第二条** 本细则适用于本行所有表内外信贷资产，包括但不限于：
- 各类贷款（企业贷款、个人贷款、贸易融资等）
- 票据贴现
- 信用证、保函、承兑汇票等表外业务
- 债券投资中具有信贷性质的资产

**第三条** 信贷资产风险分类应遵循以下原则：
1. **真实性原则**：准确揭示信贷资产实际风险水平
2. **及时性原则**：动态调整分类结果，及时反映资产质量变化
3. **审慎性原则**：对难以准确判断风险的资产，应适度下调分类等级
4. **重要性原则**：对影响资产质量的重大因素予以充分考虑

## 第二章 分类标准

### 第一节 五级分类定义

**第四条** 正常类
债务人能够履行合同，没有足够理由怀疑信贷资产本息不能按时足额偿还。

**第五条** 关注类
尽管债务人目前有能力偿还信贷资产本息，但存在一些可能对偿还产生不利影响的因素。

**第六条** 次级类
债务人的还款能力出现明显问题，完全依靠其正常营业收入无法足额偿还信贷资产本息，即使执行担保，也可能会造成一定损失。

**第七条** 可疑类
债务人无法足额偿还信贷资产本息，即使执行担保，也肯定要造成较大损失。

**第八条** 损失类
在采取所有可能的措施或一切必要的法律程序之后，本息仍然无法收回，或只能收回极少部分。

---

### 第二节 具体分类标准

#### （一）零售贷款分类标准

**第九条** 个人住房贷款
- 逾期天数 ≤ 30天：正常类
- 30天 < 逾期天数 ≤ 90天：关注类
- 90天 < 逾期天数 ≤ 180天：次级类
- 180天 < 逾期天数 ≤ 360天：可疑类
- 逾期天数 > 360天：损失类

**第十条** 个人消费贷款/信用卡
- 逾期天数 ≤ 60天：正常类
- 60天 < 逾期天数 ≤ 120天：关注类
- 120天 < 逾期天数 ≤ 180天：次级类
- 180天 < 逾期天数 ≤ 360天：可疑类
- 逾期天数 > 360天：损失类

#### （二）企业贷款分类标准

**第十一条** 定性因素（任一条件满足即可下调分类）
- 借款人管理层发生重大变化（核心技术人员流失、实际控制人变更）
- 借款人或有负债（如对外担保）大幅增加
- 借款人涉及重大诉讼、仲裁或行政处罚
- 抵押物价值大幅下跌（跌幅超过30%）
- 借款人所在行业出现系统性风险（如房地产调控政策收紧）

**第十二条** 定量指标
- 利息保障倍数 < 1.5：下调至关注类
- 资产负债率 > 80%：下调至关注类
- 连续两年经营性现金流为负：下调至次级类

#### （三）重组贷款分类

**第十三条** 重组贷款是指银行由于借款人财务状况恶化，或无力还款而对借款合同还款条款作出调整的贷款。

重组贷款至少应分类为次级类；重组后6个月内未逾期的，可上调至关注类；重组后6个月内再次逾期的，至少应分类为可疑类。

## 第三章 分类流程

**第十四条** 初分
客户经理根据贷后检查情况，在信贷管理系统中提出初分意见。

**第十五条** 复核
风险经理对初分结果进行复核，重点核查分类依据的充分性。

**第十六条** 审批
- 单笔金额 ≤ 500万元：支行行长审批
- 500万元 < 单笔金额 ≤ 2000万元：分行风险总监审批
- 单笔金额 > 2000万元：总行风险管理委员会审批

**第十七条** 分类频率
- 正常类、关注类：每季度分类一次
- 次级类、可疑类：每月分类一次
- 损失类：每半年复核一次

---

## 第四章 拨备计提

**第十八条** 根据五级分类结果，按以下比例计提贷款损失准备：

| 分类等级 | 计提比例 |
|----------|----------|
| 正常类 | 1.5% |
| 关注类 | 3% |
| 次级类 | 30% |
| 可疑类 | 60% |
| 损失类 | 100% |

**第十九条** 对于抵质押物，可按评估价值的一定比例冲减应计提拨备，但冲减比例不得超过应计提金额的50%。
